# TP5 – Activité 5-1 : Service de conversion de devise (Java RMI)
## Objectif
Application répartie permettant de convertir un montant en euros vers le dinar tunisien via Java RMI.

## Structure
- RMIConversion_Server : IConversion, ConversionImpl, ConversionServer
- RMIConversion_Client : ConversionClient
- conversionClient.jar : interface distante exportée
